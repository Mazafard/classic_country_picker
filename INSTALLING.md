# Installing

To use the `classic_country_picker` package in your Flutter project, follow these steps:

## 1. Depend on it

Add this to your package's `pubspec.yaml` file:

```yaml
dependencies:
  classic_country_picker: ^1.0.0
```

## 2. Install it

You can install packages from the command line:

with Flutter:

```bash
$ flutter pub get
```

## 3. Import it

Now in your Dart code, you can use:

```dart
import 'package:classic_country_picker/classic_country_picker.dart';
```
